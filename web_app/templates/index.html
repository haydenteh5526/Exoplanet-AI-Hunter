How It Works

From raw NASA telescope data to real-time classification in three steps.

1. Data Pipeline

Raw CSV exports from NASA's Exoplanet Archive (Kepler, K2, TESS) are standardized into a unified 9-feature schema with consistent disposition labels.

2. ML Training

A Random Forest ensemble (200 trees) trained with SMOTE class balancing on 9,487 samples. Achieves 73.7% accuracy across 3 classes.

3. Real-Time Inference

Flask API serves predictions with confidence scores, plus similarity matching against 18,396 known exoplanets for context.
